A complete web-based **Digital Library Management System** built using **PHP, MySQL, HTML, CSS, and JavaScript**.  

## Features

- Admin Module:
  - Add, edit, delete books and members
  - Generate reports on issued books and fines
  - Full control over library operations
- User Module:
  - Browse and search books
  - Issue and return books
  - View issued books and due dates
  - Email queries to admin

## Installation

1. Install **XAMPP** and start Apache & MySQL.
2. Import `sql/database.sql` into **phpMyAdmin**.
3. Update database credentials in `config/db.php`.
4. Copy the project folder to `htdocs`.
5. Open `http://localhost/digital-library/index.php`.
